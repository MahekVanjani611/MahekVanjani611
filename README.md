## 🟢 NVIDIA — System Software Engineering Intern

> **System Software • Performance Optimization • Linux • Vulkan**

Worked on system software and performance optimization, including Linux device drivers and Vulkan-related development.

### ⚡ Performance Optimization

One of the optimization tasks involved replacing a large linked-list structure with an **unrolled linked list**.

```text
Before

Node → Node → Node → Node → Node → ...
  ↓
Many pointer dereferences
Poor cache locality


                 ↓ Optimization ↓


After

[Node Node Node Node] → [Node Node Node Node] → ...
       Block-based structure

        ↓
Better cache locality
        ↓
Fewer pointer dereferences
        ↓
Faster traversal
```

### 🔧 Key Areas

`Linux Device Drivers`
`Vulkan API`
`Systems Programming`
`Data Structures`
